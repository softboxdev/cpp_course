# **Полное руководство по сборке программ на C++ в Windows для новичков**

## **📌 Что такое сборка программы?**

**Сборка (компиляция)** — это процесс превращения вашего текстового файла с кодом (`.cpp`) в исполняемый файл (`.exe`), который можно запустить на компьютере.

Процесс состоит из двух основных этапов:
1. **Компиляция** — перевод кода на C++ в машинный код (`.obj` файлы)
2. **Линковка** — соединение всех частей программы в один `.exe` файл

---

## **🎯 3 основных способа сборки в Windows**

### **Способ 1: IDE (Среда разработки) — Самый простой для новичков**

#### **Вариант A: Visual Studio 2022 Community (Бесплатно)**
1. **Скачайте** с [официального сайта](https://visualstudio.microsoft.com/ru/)
2. При установке выберите **"Разработка приложений на C++"**
3. После установки:
   - Создайте новый проект: **Файл → Новый → Проект**
   - Выберите **"Консольное приложение"**
   - Напишите код в файле `*.cpp`
   - Для сборки нажмите **F7** или меню **Сборка → Собрать решение**
   - Для запуска нажмите **F5** или **Ctrl+F5** (запуск без отладки)

#### **Вариант B: Code::Blocks (Более лёгкий вариант)**
1. **Скачайте** с [официального сайта](http://www.codeblocks.org/)
2. Выберите версию с **MinGW** в названии (например, `codeblocks-20.03mingw-setup.exe`)
3. После запуска:
   - Создайте новый проект: **File → New → Project**
   - Выберите **Console application**
   - Напишите код, нажмите **F9** для сборки и запуска

**Преимущества IDE:** Всё в одном месте, не нужно настраивать компилятор, удобная отладка.

### **Способ 2: Компилятор в командной строке**

#### **Шаг 1: Установите MinGW-w64 (компилятор GCC для Windows)**
1. **Скачайте** установщик с [SourceForge](https://sourceforge.net/projects/mingw-w64/)
   - Или используйте [MSYS2](https://www.msys2.org/) (рекомендуется)
   
2. **Установка через MSYS2:**
   ```powershell
   # 1. Установите MSYS2 с официального сайта
   # 2. Запустите "MSYS2 MSYS" из меню Пуск
   # 3. Обновите пакеты:
   pacman -Syu
   # 4. Установите MinGW-w64:
   pacman -S --needed base-devel mingw-w64-x86_64-toolchain
   # 5. Добавьте в PATH: C:\msys64\mingw64\bin
   ```

#### **Шаг 2: Добавьте компилятор в PATH (Переменные среды)**
1. Нажмите **Win + R**, введите `sysdm.cpl`, Enter
2. **Дополнительно → Переменные среды**
3. В "Переменные среды пользователя" найдите `PATH`, нажмите **Изменить**
4. **Добавьте** путь к компилятору (например: `C:\msys64\mingw64\bin`)
5. **Сохраните** и перезапустите командную строку

#### **Шаг 3: Проверьте установку**
Откройте **Командную строку** или **PowerShell** и введите:
```cmd
g++ --version
```
Должна появиться информация о версии компилятора.

#### **Шаг 4: Компиляция программы**
1. **Создайте файл** `hello.cpp` с кодом:
```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello, World!" << endl;
    return 0;
}
```

2. **Откройте командную строку** в папке с файлом:
   - Перейдите в папку: `cd C:\Users\ВашеИмя\Documents\Cpp`
   - Или откройте проводник, зайдите в папку, зажмите **Shift + ПКМ**, выберите **"Открыть окно PowerShell здесь"**

3. **Скомпилируйте программу:**
```cmd
# Простая компиляция (создаст a.exe в Windows)
g++ hello.cpp

# Компиляция с указанием имени выходного файла
g++ hello.cpp -o myprogram.exe

# Компиляция с отладочной информацией
g++ hello.cpp -o myprogram.exe -g

# Компиляция с оптимизацией
g++ hello.cpp -o myprogram.exe -O2
```

4. **Запустите программу:**
```cmd
myprogram.exe
# или
.\myprogram.exe
```

### **Способ 3: Современные инструменты (CMake, VSCode)**

#### **Сборка с помощью CMake + VSCode**
1. **Установите VSCode** с [официального сайта](https://code.visualstudio.com/)
2. Установите расширения:
   - **C/C++** (от Microsoft)
   - **CMake Tools** (если используете CMake)

3. **Минимальная структура проекта:**
```
ваш_проект/
├── CMakeLists.txt
└── src/
    └── main.cpp
```

4. **Содержимое CMakeLists.txt:**
```cmake
cmake_minimum_required(VERSION 3.10)
project(MyFirstProject)

# Указываем стандарт C++
set(CMAKE_CXX_STANDARD 17)

# Добавляем исполняемый файл
add_executable(myapp src/main.cpp)
```

5. В VSCode откройте папку проекта, нажмите **F1 → CMake: Configure**
6. Для сборки: **F7** или в палитре команд **CMake: Build**

## **🔧 Часто используемые флаги компиляции**

```cmd
# Основные флаги g++:
g++ файл.cpp -o программа.exe  # Указать имя выходного файла
g++ файл.cpp -Wall             # Включить ВСЕ предупреждения (очень важно!)
g++ файл.cpp -Werror           # Превратить предупреждения в ошибки
g++ файл.cpp -std=c++17        # Использовать стандарт C++17
g++ файл.cpp -O2               # Включить оптимизацию
g++ файл.cpp -g                # Добавить отладочную информацию

# Компиляция нескольких файлов:
g++ main.cpp functions.cpp -o program.exe
```

## **🚀 Практический пример: Пошаговая инструкция**

### **Пример 1: Простая программа из одного файла**

1. **Создайте папку** `C:\CppProjects\First`
2. **Создайте файл** `main.cpp` в этой папке:
```cpp
#include <iostream>

int main() {
    std::cout << "Моя первая программа на C++!" << std::endl;
    int a = 5, b = 3;
    std::cout << a << " + " << b << " = " << (a + b) << std::endl;
    return 0;
}
```

3. **Откройте PowerShell** в этой папке (Shift + ПКМ → "Открыть окно PowerShell здесь")
4. **Скомпилируйте:**
```powershell
g++ main.cpp -o myapp.exe -Wall
```
5. **Запустите:**
```powershell
.\myapp.exe
```

### **Пример 2: Программа из нескольких файлов**

1. **Структура проекта:**
```
calculator/
├── main.cpp
├── math_functions.cpp
└── math_functions.h
```

2. **math_functions.h:**
```cpp
#ifndef MATH_FUNCTIONS_H
#define MATH_FUNCTIONS_H

int add(int a, int b);
int multiply(int a, int b);

#endif
```

3. **math_functions.cpp:**
```cpp
#include "math_functions.h"

int add(int a, int b) {
    return a + b;
}

int multiply(int a, int b) {
    return a * b;
}
```

4. **main.cpp:**
```cpp
#include <iostream>
#include "math_functions.h"

int main() {
    std::cout << "Сумма: " << add(5, 3) << std::endl;
    std::cout << "Произведение: " << multiply(5, 3) << std::endl;
    return 0;
}
```

5. **Компиляция:**
```cmd
g++ main.cpp math_functions.cpp -o calculator.exe -Wall
```

## **🚨 Частые проблемы и решения**

### **Проблема 1: "g++ не является внутренней или внешней командой"**
**Решение:** Компилятор не добавлен в PATH. Проверьте шаг 2 способа 2.

### **Проблема 2: Ошибка "undefined reference"**
**Решение:** Вы забыли скомпилировать все `.cpp` файлы:
```cmd
# Неправильно:
g++ main.cpp -o program.exe
# Правильно:
g++ main.cpp functions.cpp other.cpp -o program.exe
```

### **Проблема 3: Ошибки с кириллицей в консоли**
**Решение:** Используйте setlocale или работайте с UTF-8:
```cpp
#include <iostream>
#include <clocale>

int main() {
    setlocale(LC_ALL, "Russian");
    // или для Windows:
    // SetConsoleCP(1251);
    // SetConsoleOutputCP(1251);
    std::cout << "Привет, мир!" << std::endl;
}
```

### **Проблема 4: Программа сразу закрывается**
**Решение:** Добавьте ввод в конце:
```cpp
#include <iostream>

int main() {
    std::cout << "Hello!" << std::endl;
    
    // Способ 1: Ожидание нажатия Enter
    std::cin.get();
    
    // Способ 2: Ввод числа
    // int x;
    // std::cin >> x;
    
    return 0;
}
```

Или запускайте через командную строку.

## **🎯 Рекомендации для начала**

1. **Начните с Visual Studio Community** — минимум проблем с настройкой
2. **Пишите простые программы** из одного файла
3. **Изучите базовые флаги компиляции:** `-o`, `-Wall`
4. **Привыкайте читать ошибки компиляции** — они указывают на строку с проблемой
5. **Сохраняйте исходный код** в отдельной папке для каждого проекта

## **Полезные команды для PowerShell:**
```powershell
# Перейти в папку
cd C:\ваша_папка

# Показать файлы в папке
dir  # или ls

# Скомпилировать все .cpp файлы в папке
g++ *.cpp -o program.exe

# Очистить скомпилированные файлы
del *.exe
del *.o
```
