# Объявление и определение функций в C++

## Полное объяснение на простом примере

### **Пример программы**
```cpp
// Объявление функции (прототип) - говорим компилятору, что такая функция будет
int calculateSum(int firstNumber, int secondNumber);

// Объявление функции с параметром по ссылке
void modifyNumber(int& numberToModify);

// Объявление функции с параметром по константной ссылке
void printNumber(const int& numberToPrint);

int main() {  // main - специальная функция, точка входа в программу
    int a = 5;     // Объявление и инициализация переменной a типа int
    int b = 10;    // Объявление и инициализация переменной b типа int
    
    // Вызов функции calculateSum с параметрами a и b
    // a и b передаются ПО ЗНАЧЕНИЮ (копируются)
    int result = calculateSum(a, b);
    
    std::cout << "Сумма: " << result << std::endl;  // Вывод результата
    
    // Вызов функции modifyNumber с параметром a
    // a передается ПО ССЫЛКЕ (не копируется, работаем с оригиналом)
    modifyNumber(a);
    
    std::cout << "Измененное a: " << a << std::endl;
    
    // Вызов функции printNumber с параметром a
    // a передается ПО КОНСТАНТНОЙ ССЫЛКЕ (только для чтения)
    printNumber(a);
    
    return 0;  // Возвращаем 0 - код успешного завершения
}

// ОПРЕДЕЛЕНИЕ функции calculateSum (реализация)
// int - тип возвращаемого значения
// calculateSum - имя функции
// (int firstNumber, int secondNumber) - параметры функции
int calculateSum(int firstNumber, int secondNumber) {
    // firstNumber и secondNumber - КОПИИ значений из main()
    int sum = firstNumber + secondNumber;  // Создаем локальную переменную sum
    return sum;  // Возвращаем значение sum в место вызова функции
}

// Определение функции modifyNumber
// void - функция не возвращает значение
// (int& numberToModify) - параметр по ССЫЛКЕ (амперсанд &)
void modifyNumber(int& numberToModify) {
    // numberToModify - это ССЫЛКА на переменную a из main()
    // Работаем напрямую с оригинальной переменной
    numberToModify = numberToModify * 2;  // Умножаем оригинальное значение на 2
    // Здесь нет return, так как функция возвращает void
}

// Определение функции printNumber
// (const int& numberToPrint) - параметр по КОНСТАНТНОЙ ссылке
void printNumber(const int& numberToPrint) {
    // numberToPrint - ссылка только для чтения
    // Мы не можем изменить оригинальную переменную
    std::cout << "Число: " << numberToPrint << std::endl;
}
```

## Подробное объяснение каждого понятия

### **1. Объявление функции (Function Declaration / Прототип)**

```cpp
// Объявление (прототип) функции
// ├── тип возвращаемого значения
// │        ├── имя функции
// │        │        ├── параметры в скобках
// ▼        ▼        ▼
int calculateSum(int firstNumber, int secondNumber);
//           ▲
//           └── точка с запятой обязательна для объявления
```

**Зачем нужно объявление?**
- Сообщает компилятору о существовании функции до её использования
- Позволяет вызывать функцию до её определения
- Определяет интерфейс функции (что она принимает и возвращает)

### **2. Определение функции (Function Definition)**

```cpp
// Определение (реализация) функции
// ┌── тип возвращаемого значения
// │        ┌── имя функции (должно совпадать с объявлением)
// │        │        ┌── параметры (типы и имена)
// ▼        ▼        ▼
int calculateSum(int firstNumber, int secondNumber) {
    //       ▲
    //       └── фигурные скобки {} - тело функции
    
    // Тело функции - код, который выполняется при вызове
    int sum = firstNumber + secondNumber;  // Локальная переменная
    return sum;  // Ключевое слово return
    //         ▲
    //         └── возвращаемое значение (должно соответствовать типу)
}
```

### **3. Параметры по значению (Pass by Value)**

```cpp
void functionByValue(int parameter) {
    // parameter - КОПИЯ исходного значения
    parameter = 100;  // Изменяется только копия
    // Оригинальная переменная в вызывающем коде НЕ меняется
}

int main() {
    int x = 5;
    functionByValue(x);  // x передается по значению
    // x всё еще равно 5, а не 100
}
```

**Как это работает:**
1. При вызове функции создается КОПИЯ переменной
2. Функция работает с копией
3. После завершения функции копия уничтожается
4. Оригинальная переменная не меняется

**Когда использовать:**
- Для простых типов (int, double, char)
- Когда не нужно менять исходные значения
- Для небольших объектов

### **4. Параметры по ссылке (Pass by Reference)**

```cpp
void functionByReference(int& parameter) {
    //        ▲
    //        └── амперсанд & означает "ссылка"
    
    // parameter - ССЫЛКА на оригинальную переменную
    // Это не новая переменная, а псевдоним существующей
    parameter = 100;  // Изменяется оригинальная переменная
}

int main() {
    int x = 5;
    functionByReference(x);  // x передается по ссылке
    // x теперь равно 100
}
```

**Как это работает:**
1. Функция получает "ссылку" (адрес) на оригинальную переменную
2. Работает напрямую с оригинальной переменной
3. Экономит память (нет копирования)
4. Позволяет изменять оригинальные значения

**Когда использовать:**
- Для изменения входных параметров
- Для передачи больших объектов (чтобы избежать копирования)
- Когда нужно вернуть несколько значений

### **5. Константные ссылки (Const References)**

```cpp
void functionByConstReference(const int& parameter) {
    //        ▲      ▲
    //        │      └── амперсанд для ссылки
    //        └── const означает "только для чтения"
    
    // Мы можем читать parameter, но НЕ можем изменять
    std::cout << parameter;  // OK
    // parameter = 100;      // ОШИБКА: нельзя изменить const параметр
}

int main() {
    int x = 5;
    functionByConstReference(x);  // Безопасная передача
}
```

**Преимущества:**
- Нет копирования (как у ссылки)
- Гарантия, что оригинальное значение не изменится
- Можно передавать временные значения

### **6. Возвращаемые значения**

```cpp
// 1. Возврат по значению (обычный)
int getValue() {
    int x = 42;
    return x;  // Возвращается КОПИЯ x
}

// 2. Возврат по ссылке
int& getReference(int& x) {
    return x;  // Возвращается ССЫЛКА на x
}

// 3. Возврат по константной ссылке
const int& getConstReference(const int& x) {
    return x;  // Возвращается константная ссылка
}
```

## Развернутый пример с комментариями

```cpp
#include <iostream>
#include <string>

// ========== ОБЪЯВЛЕНИЯ ФУНКЦИЙ ==========

// 1. Функция для вычисления площади прямоугольника
// Параметры по значению - защита от случайного изменения
double calculateArea(double width, double height);

// 2. Функция для обмена значений двух переменных
// Параметры по ссылке - хотим изменить оригинальные значения
void swapValues(int& first, int& second);

// 3. Функция для форматированного вывода
// Параметр по константной ссылке - большой объект, не хотим копировать
void printFormatted(const std::string& text);

// ========== ГЛАВНАЯ ФУНКЦИЯ ==========
int main() {
    // Пример 1: Параметры по значению
    double rectWidth = 5.5;
    double rectHeight = 3.2;
    
    // Вызываем функцию, передавая КОПИИ значений
    double area = calculateArea(rectWidth, rectHeight);
    
    std::cout << "Площадь прямоугольника " 
              << rectWidth << "x" << rectHeight 
              << " = " << area << std::endl;
    
    // Пример 2: Параметры по ссылке
    int a = 10;
    int b = 20;
    
    std::cout << "\nДо обмена: a = " << a << ", b = " << b << std::endl;
    
    // Передаем ССЫЛКИ на a и b, функция может их изменить
    swapValues(a, b);
    
    std::cout << "После обмена: a = " << a << ", b = " << b << std::endl;
    
    // Пример 3: Константные ссылки
    std::string message = "Привет, мир! Это длинная строка для демонстрации.";
    
    // Передаем по константной ссылке - не копируем всю строку
    printFormatted(message);
    
    return 0;
}

// ========== ОПРЕДЕЛЕНИЯ ФУНКЦИЙ ==========

// 1. Реализация calculateArea
double calculateArea(double width, double height) {
    // width и height - локальные копии
    // Можем спокойно с ними работать, не боясь изменить оригиналы
    
    double result = width * height;  // Вычисляем площадь
    
    // Для демонстрации: изменение параметров не влияет на main()
    width = 0;   // Изменяем только копию
    height = 0;  // Оригиналы в main() остаются неизменными
    
    return result;  // Возвращаем вычисленное значение
}

// 2. Реализация swapValues
void swapValues(int& first, int& second) {
    // first и second - ссылки на переменные в main()
    // Работаем напрямую с a и b из main()
    
    int temp = first;   // Сохраняем значение first во временной переменной
    first = second;     // Присваиваем first значение second
    second = temp;      // Присваиваем second сохраненное значение
    
    // После завершения функции значения a и b в main() поменяются местами
}

// 3. Реализация printFormatted
void printFormatted(const std::string& text) {
    // text - константная ссылка на строку в main()
    // Можем читать, но не можем изменять
    
    std::cout << "\n======= ФОРМАТИРОВАННЫЙ ВЫВОД =======\n";
    std::cout << "Текст: " << text << std::endl;
    std::cout << "Длина текста: " << text.length() << " символов\n";
    std::cout << "====================================\n";
    
    // Следующая строка вызвала бы ошибку компиляции:
    // text.clear();  // ОШИБКА: нельзя изменить const параметр
}
```

## Ключевые различия наглядно

```cpp
#include <iostream>

// Три версии одной функции с разными типами параметров
void byValue(int x) {
    x = 100;
    std::cout << "Внутри byValue: x = " << x << std::endl;
}

void byReference(int& x) {
    x = 100;
    std::cout << "Внутри byReference: x = " << x << std::endl;
}

void byConstReference(const int& x) {
    // x = 100;  // Ошибка компиляции!
    std::cout << "Внутри byConstReference: x = " << x << std::endl;
}

int main() {
    int number = 5;
    
    std::cout << "Начальное значение: " << number << "\n\n";
    
    byValue(number);
    std::cout << "После byValue: " << number << "\n\n";
    
    byReference(number);
    std::cout << "После byReference: " << number << "\n\n";
    
    byConstReference(number);
    std::cout << "После byConstReference: " << number << std::endl;
    
    return 0;
}

/*
ВЫВОД ПРОГРАММЫ:
Начальное значение: 5

Внутри byValue: x = 100
После byValue: 5          // Не изменилось!

Внутри byReference: x = 100
После byReference: 100    // Изменилось!

Внутри byConstReference: x = 100
После byConstReference: 100
*/
```

## Практические рекомендации

### **Когда что использовать:**

1. **По значению:**
   - Простые типы (int, double, bool, char)
   - Когда не нужно менять оригинал
   - Небольшие структуры (до 16 байт)

2. **По ссылке (без const):**
   - Когда нужно изменить входной параметр
   - Для реализации функций обмена (swap)
   - Когда нужно вернуть несколько значений

3. **По константной ссылке:**
   - Большие объекты (строки, векторы, классы)
   - Когда нужно только читать данные
   - Для безопасности (защита от случайных изменений)

### **Пример выбора правильного типа параметра:**

```cpp
// ПЛОХО: копирование большого вектора
void processVector(std::vector<int> data) {
    // Работа с копией - неэффективно
}

// ХОРОШО: константная ссылка
void processVector(const std::vector<int>& data) {
    // Работа с оригиналом без копирования
    // Не можем случайно изменить исходные данные
}

// ХОРОШО: ссылка (если нужно изменить)
void modifyVector(std::vector<int>& data) {
    // Можем изменять оригинальный вектор
}
```

## Итоговая таблица

| Способ передачи | Синтаксис | Копирование? | Можно изменить оригинал? | Когда использовать |
|----------------|-----------|--------------|-------------------------|-------------------|
| По значению | `void func(Type param)` | Да | Нет | Простые типы, небольшие объекты |
| По ссылке | `void func(Type& param)` | Нет | Да | Нужно изменить параметр |
| По константной ссылке | `void func(const Type& param)` | Нет | Нет | Большие объекты, только чтение |

## Заключение

Понимание разницы между передачей параметров по значению и по ссылке критически важно для:
- Эффективности (избегаем ненужного копирования)
- Безопасности (защищаем данные от случайных изменений)
- Функциональности (возможность изменения входных параметров)

Практикуйтесь с разными типами параметров, чтобы интуитивно понимать, какой подход лучше в каждой конкретной ситуации.
